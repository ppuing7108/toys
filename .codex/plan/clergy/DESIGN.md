# 목사 신부 스님 심리테스트 개발 설계서

이 문서는 Claude가 GitHub Pages용 정적 심리테스트를 구현하기 위한 기준이다. 사용자와 Codex는 설계 및 이미지 리소스를 담당하고, Claude는 서비스 구현과 검증을 담당한다. 아래 문항과 결과 문구는 검토 가능한 1차 초안이며, 구현 후 플레이테스트로 다듬는다.

## 1. 구현 범위

- 서비스 경로: `psychology-tests/clergy/index.html`
- 루트 `index.html` → `psychology-tests/index.html` → 개별 테스트로 이동하는 목록 구성
- Downloads의 기존 목사·신부·스님 HTML을 참고하되 20문항·4보기·새 결과 화면으로 개편
- HTML, CSS, JavaScript로 구현하고 빌드 도구는 필수로 두지 않는다.
- 서버, 계정, 결과 업로드 없이 GitHub Pages에서 작동한다.
- 예상 주소: https://ppuing7108.github.io/toys/psychology-tests/clergy/ (아직 배포 확인 전)
- 사이트 링크와 리소스 경로는 `/toys/` 하위에서도 작동하는 상대 경로로 작성한다.

## 2. 제공 파일

| 파일 | 역할 |
| --- | --- |
| `DESIGN.md` | 개발자가 읽을 전체 설계 및 콘텐츠 |
| `brief.json` | 화면·채점·공유·검수 기준의 구조화 데이터 |
| `questions.json` | 20문항, 80개 보기, 고정 ID, 점수 |
| `results.json` | 세 유형의 전체 결과 문구와 출처 |
| `assets/pastor.png` | 목사형 대표 일러스트 |
| `assets/priest.png` | 신부형 대표 일러스트 |
| `assets/monk.png` | 스님형 대표 일러스트 |
| `image-prompts.json` | 내장 image_gen으로 제작한 이미지의 최종 프롬프트 |

이미지는 각 1254×1254 PNG이며 실제 서비스의 assets/로 복사해 사용한다. 리소스 최적화가 필요하면 원본은 보존하고 별도 압축본을 만든다. 이미지 안의 글자는 없으며, 결과 문구는 웹과 공유 이미지에서 별도로 조판한다.

## 3. 화면 흐름

소개 → 20문항 → 결과 → 이미지와 링크 공유. 공유된 결과 링크로 들어오면 해당 결과를 먼저 보여 주고 나도 테스트하기를 제공한다.

- **소개 문구:** 나는 목사일까, 신부일까, 스님일까? / 뜻밖의 일상 상황 20개로 알아보는 나의 마음 씀씀이 / 약 4~5분

- **문항 수:** 20

- **보기 수:** 4

- **순서 섞기:** 매 시작 및 다시 하기에서 문항 배열과 각 문항의 보기 배열을 독립적으로 Fisher–Yates 셔플. 진행 중 재렌더링이나 뒤로 가기에서는 기존 순서 유지. ID에 응답을 연결하고 인덱스로 채점하지 않음.

- **이동과 응답 수정:** 한 화면 한 문항. 이전 문항 버튼과 7 / 20 형태 진행률 제공. 답을 바꾸면 이전 점수 제거 또는 응답 전체로 재계산. 마지막 응답 전 확정 결과를 노출하지 않음.

- **진행 속도:** 선택 즉시 반응 후 180~250ms 전환. 화면 전환 후 질문으로 포커스. 5문항마다 짧은 진행 문구, 진행을 막는 중간 화면은 넣지 않음.

- **문항 편집 원칙:** 선택지는 비슷한 길이와 매력으로 유지. 정답이나 도덕적으로 좋은 답처럼 보이는 표현 최소화. 순서 셔플만으로 의도가 완전히 숨겨지지는 않으며 플레이테스트로 보완.

## 4. 채점 규칙


### 성향 축


- **목사형 P:** 사람을 연결하고 격려하는 성향

- **신부형 C:** 책임지고 꾸준히 돌보는 성향

- **스님형 M:** 관찰하고 유연하게 내려놓는 성향

- **점수와 비율:** 선택지 weights를 P,C,M 순으로 합산. 각 응답 합은 6, 총합은 120. 표시 비율=각 점수/120*100. 정수 비율은 내림 후 남은 값을 소수부가 큰 순서로 배분해 합계 100.

- **기대점수 균형:** 18개 문항의 혼합 답은 PC,CM,MP를 각각 6개 배치하고 2개는 균형 답으로 구성. 모든 보기를 균등 선택했을 때 총 기대점수가 각 유형 40점으로 동일. 실제 이용자 분포에 대한 검증은 별도 필요.

- **결과 해석:** 비율은 이 테스트 안에서의 상대적 성향. 종교 적합도, 실제 성직자의 성격, 임상적 성격 확률을 뜻하지 않음. 1% 단위 정밀도에 과도한 의미를 주지 않음.

- **주 유형과 보조 성향:** 최고 점수 유형을 주 결과로 사용. 단독 1위이고 2위가 단독이면 secondary 설명 추가. 2위가 동점이면 두 성향이 고르게 함께하는 유형이라고 표시.

- **동점 처리:** 최고 점수 동점은 마지막 답이나 P 우선으로 깨지 않음. 공동 1위 배지와 각 유형을 함께 표시하고 일러스트 2개를 같은 크기로 배치. 세 유형 동점이면 균형형, 세 이미지를 함께 표시.

- **가까운 결과:** 상위 두 비율 차이가 5%p 이하면 두 성향이 가까워요 문구. 이 기준은 편집용 휴리스틱이며 검증된 심리 척도가 아님.

- **채점 방식의 특성:** 모든 답에 최소 점수를 주는 혼합 방식 때문에 결과 비율은 극단적인 100%까지 나오지 않음. 불확실성을 높이는 장치로 채택. 원점수와 동점 규칙은 질문 순서에 영향을 받지 않음.

완전 동점 결과에는 세 일러스트를 같은 크기로 배치하고, 두 유형 공동 1위에는 두 이미지를 나란히 배치한다. 별도의 혼합형 이미지는 필요하지 않다. 점수는 질문 순서나 마지막 응답으로 조정하지 않는다.

## 6. 종교 사상과 문구 원칙


- **사상 연결 원칙:** 목사형·신부형·스님형은 놀이를 위한 비유. 교리에서 성격 분류가 도출되었다고 주장하지 않음. 개신교와 가톨릭의 공통 신앙을 명시하고 한쪽만 사랑/섬김을 가진 것처럼 쓰지 않음.

- **인용 원칙:** 확인하지 않은 유명인 명언은 쓰지 않음. results.json reflection은 직인용이 아닌 의역 또는 창작 문장으로 표시. 제목은 명언 대신 나에게 건네는 한 문장.

- **하단 안내:** 재미로 보는 성향 테스트입니다. 실제 종교인의 성격이나 신앙을 판정하지 않습니다.

## 7. 결과 이미지 및 링크 공유


- **공유 기본 동작:** 결과 이미지와 테스트 링크를 함께 제공. 결과 도달 시 로컬에서 공유 PNG를 미리 생성하고, 준비 완료 후 공유 버튼 활성화.

### 공유 이미지


- **크기:** 1080 × 1350

- **형식:** image/png

- **안전 여백:** 72

**포함 내용**

1. 테스트 제목
2. 유형명·별명
3. 대표 일러스트
4. 키워드 3개
5. 성향 비율
6. 나에게 건네는 한 문장과 짧은 출처
7. 테스트하기 안내
8. 짧은 사이트 주소와 QR 코드

- **주의점:** 긴 해설은 이미지에 넣지 않음. QR은 아래의 결과 링크로 생성해 복사본만 전달되어도 재접속 가능. 공동 1위·균형형 카드도 지원. Canvas 렌더링 시 로컬 이미지·폰트 준비 완료를 기다려 깨진 이미지와 대체 폰트를 방지.

- **결과 링크:** 기본 주소 + #v=1&p=50&c=30&m=40. p,c,m은 퍼센트가 아닌 총점이며 합계 120. 버전·정수·범위·합계를 검증하고 잘못된 값은 소개 화면으로 이동. URL 복원 결과는 공유된 결과로 표시하고 나도 테스트하기 버튼 제공. 실제 응답 기록은 URL에 넣지 않음.

- **기기 공유 기능:** navigator.canShare({files:[pngFile]}) 지원을 확인해 navigator.share({files:[pngFile],title,text,url})를 사용. 사용자 버튼 클릭에서 호출하고 PNG 생성으로 사용자 활성화가 만료되지 않도록 미리 준비. 목적지 앱이 URL/text를 누락할 수 있으므로 이미지에도 주소/QR 포함. AbortError는 취소로 처리.

- **저장과 복사 대안:** 파일 공유 미지원 환경에는 이미지 저장과 링크 복사 버튼을 항상 제공. 파일 공유 실패 시 사용자가 다시 선택하도록 안내하고 자동 재호출하지 않음. 모바일 다운로드가 이미지 미리보기로 열리면 길게 눌러 저장 안내.

- **링크 미리보기:** 개인별 해시 결과는 크롤러가 실행하지 않을 수 있어 공유 미리보기의 개인화를 약속하지 않음. 초기 범위는 공통 OG 이미지와 정확한 첨부 결과 이미지. 유형별 OG 미리보기가 필요해지면 실제 정적 HTML 경로와 OG 이미지를 별도 생성.

- **정적 호스팅:** 서버·로그인·외부 업로드 없이 브라우저와 GitHub Pages로 구현 가능. 결과 URL은 누구나 수정할 수 있는 놀이용 데이터.

### 구현 시 보완 조건

- 이미지 생성은 결과 화면이 완성된 뒤 미리 수행한다. 사용자가 공유 버튼을 누른 시점에는 PNG File을 즉시 사용할 수 있어야 한다.
- `document.fonts.ready`, 일러스트 로딩, QR 준비를 기다린 뒤 공유 이미지를 생성한다. 준비 중 표시를 제공하고 오류 시 다시 생성할 수 있게 한다.
- 폰트와 일러스트는 가능한 한 동일 출처에서 로드해 Canvas 보안 오류를 방지한다. 외부 이미지 URL을 직접 그리지 않는다.
- URL의 점수는 원점수다. v=1, P/C/M 모두 정수 0~80, 총합 120을 확인한다. 검증 실패 시 경고성 오류 화면 대신 소개 화면에서 시작한다.
- 공유 링크 복원은 이미 존재하는 결과를 보는 기능이다. 진짜 응답이 검증되었다고 표시하지 않는다.
- QR 생성 라이브러리를 쓰면 라이선스를 확인하고 고정 버전을 로컬에 둔다. 외부 QR 생성 서버로 결과 링크를 보내지 않는다.
- 링크 복사가 불가능하면 선택 가능한 URL과 직접 복사 안내를 제공한다.
- 파일 공유 API 호출 성공은 상대방의 수신 확인이 아니다. 공유 요청을 열었다는 정도로만 처리한다.

## 9. 유형별 결과 문구

### 목사형 — 사람을 모으는 온기

**단톡방에 불을 켜는 사람**

키워드: 연결 · 격려 · 실행

누군가 혼자 남지 않았는지 먼저 살피는 편이에요. 어색한 자리에서는 첫 말을 꺼내고, 막막한 상황에서는 같이 해 보자고 손을 내밉니다. 당신의 다정함은 종종 사람을 움직이는 추진력이 돼요.

**잘하는 것:** 사람들의 장점을 발견하고 함께 움직일 이유를 만드는 힘.

**피곤해지는 순간:** 모두의 분위기를 책임지려다 내 마음의 배터리를 놓칠 수 있어요.

**오늘의 작은 실천:** 오늘은 한 사람을 격려한 뒤, 나를 위한 약속도 하나 잡아 보세요.

#### 받은 것을 나누는 섬김

베드로전서 4장 10절은 각자 받은 은사를 다른 이를 섬기는 데 쓰도록 권합니다. 이 테스트는 그 가르침을 사람을 잇고 서로의 장점을 살리는 모습과 연결했어요. 이 가치는 가톨릭을 포함한 그리스도교가 공유합니다.

**나에게 건네는 한 문장:** 내가 잘하는 일이 누군가에게 힘이 될 수 있다.

베드로전서 4:10의 뜻을 풀어 쓴 문장 · [근거 원문](https://www.biblegateway.com/passage/?search=1+Peter+4%3A10&version=NIV)

**2위 성향에 따른 설명**

- C: 따뜻함을 꾸준한 약속으로 바꾸는 목사형
- M: 함께하되 상대의 속도를 기다려 주는 목사형

### 신부형 — 곁을 지키는 다정함

**말보다 오래 남는 안심**

키워드: 돌봄 · 성실 · 책임

큰 말 한마디보다 오래 지킬 수 있는 작은 약속을 선택하는 편이에요. 누가 무엇을 필요로 하는지 살피고, 혼란스러울수록 당장 할 수 있는 일부터 챙깁니다. 함께하는 사람은 당신 덕분에 한숨 돌릴 틈을 얻어요.

**잘하는 것:** 관심을 구체적인 행동과 꾸준한 돌봄으로 바꾸는 힘.

**피곤해지는 순간:** 내가 끝까지 감당해야 한다는 마음이 너무 무거워질 수 있어요.

**오늘의 작은 실천:** 오늘 지킬 작은 약속 하나와, 부탁할 도움 하나를 골라 보세요.

#### 사랑을 생활의 실천으로

가톨릭 교리서는 애덕을 하느님을 사랑하고 이웃을 자신처럼 사랑하는 덕으로 설명하며, 그 열매로 기쁨과 평화와 자비를 말합니다. 이 테스트는 그 가르침을 꾸준히 곁을 지키는 돌봄과 연결했어요. 사랑과 섬김은 개신교에서도 소중히 여기는 가치입니다.

**나에게 건네는 한 문장:** 사랑은 오늘 내가 건네는 작은 돌봄에서도 자란다.

가톨릭 교리서 1822·1829항에서 착안한 창작 문장 · [근거 원문](https://www.vatican.va/content/catechism/en/part_three/section_one/chapter_one/article_7/ii_the_theological_virtues.index.html)

**2위 성향에 따른 설명**

- P: 필요할 때 먼저 손을 내미는 신부형
- M: 상대를 서두르게 하지 않고 지켜 주는 신부형

### 스님형 — 마음에 여백을 만드는 지혜

**한 박자 쉬면 보이는 것들**

키워드: 관찰 · 유연함 · 내려놓음

계획이나 감정에 휩쓸릴 때 한 발 물러나 바라보는 편이에요. 꼭 붙잡아야 할 것과 잠시 흘려보내도 될 것을 가려냅니다. 당신이 만드는 여백 덕분에 주변도 조금 덜 조급해져요.

**잘하는 것:** 변하는 상황을 받아들이고 다음 선택의 여지를 찾는 힘.

**피곤해지는 순간:** 괜찮다는 말이 너무 빠르면 상대는 내 마음을 모른다고 느낄 수 있어요.
